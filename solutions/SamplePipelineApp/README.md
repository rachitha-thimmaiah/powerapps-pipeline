# SamplePipelineApp

This folder is the placeholder for the sample solution. It is disabled in `catalog/solutions.json` until an unmanaged export from L48 DEV is unpacked here.

Follow [docs/sample-solution.md](../../docs/sample-solution.md). `scripts/Export-Solution.ps1` replaces this note with `Other/Solution.xml` and the canvas app, flow, and table source, then sets `enabled` to true.

Do not hand-write `Solution.xml`. Pack and import need a real unpack from Dataverse, with package type Both.
